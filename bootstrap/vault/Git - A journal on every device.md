# A journal on every device

Keep personal notes close, and share changes when you are ready.

| Button | What it means |
| --- | --- |
| Check status | Find out what needs attention. |
| Commit locally | Save a version on this computer. Nothing is uploaded. |
| Pull | Bring in remote changes when the local branch can fast-forward. |
| Merge | Save local work and combine it with remote changes. Nothing is uploaded. |
| Push | Upload commits already saved locally. |
| Finish merge | Commit a merge after its conflicts have been resolved and staged. |
| Sync now | Run the complete save-and-sync workflow. |
| Force merge | Resolve conflicting edits using the chosen local or remote preference. Review the confirmation; this can discard one side of a conflicting edit. It does not force-push. |

For the screenshot, open the manual Git tools or plugin settings. Capture the explanatory labels and buttons. You do not need to run an operation, change a remote, or manufacture a conflict in your real vault. Hide any personal paths or remote addresses before publishing.
