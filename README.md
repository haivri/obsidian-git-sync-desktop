# Vault Git Sync Plugin

Canonical source for the desktop Obsidian ribbon plugin installed as
`.obsidian/plugins/vault-git-sync` in both local vaults.

After changing it, copy `main.js` and `manifest.json` into each vault's plugin
folder, confirm the SHA-256 hashes match, then reload Obsidian.

Before committing, review `git status --short` and `git diff --cached`, then use
a result-oriented message such as `git commit -m "Clarify ribbon sync status"`.
